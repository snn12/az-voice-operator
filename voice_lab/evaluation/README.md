# Evaluation

Planned scoring rubrics, reports, and decision memos for the Voice Lab.

Expected contents:

- `rubric.md` — scoring definitions and pass thresholds.
- `reports/` — versioned experiment reports.
- `decision-memo.md` — provider recommendation and rationale.

A report is only valid when it includes:

- Experiment ID and build/commit.
- Date, environment, and provider configuration.
- Sample size and composition.
- Median and P95 for latency metrics.
- Failures and exclusions, with reasons.
- Raw result location.
